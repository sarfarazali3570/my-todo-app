# 📝 To-Do List React App

This is a simple and functional To-Do List application built using **React**, **Vite**, and **Tailwind CSS**. The app allows users to **add**, **edit**, **delete**, and **mark tasks as completed**. It demonstrates the use of React **functional components**, **state**, **props**, **event handling**, and **dynamic rendering**.

---

## 📌 Features

- Add new tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Dynamic rendering of the to-do list
- Clean and responsive UI with Tailwind CSS
